# 孙笑川吧 · 抽象智能体

一个百度贴吧风格的单文件网页，内置"孙笑川"抽象人设，通过浏览器直连免费大模型 API 实现实时对线。非商用、个人娱乐向作品。

## ✨ 效果

- 高仿贴吧界面：顶部导航、吧横幅、楼层、点赞、快捷对线标签
- AI 以「孙笑川（bot）」身份逐字流式回帖，带多轮上下文记忆
- 抽象人设提示词：绷不住了 / 典中典 / 我直接一个 / 勿cue ...
- 内置安全底线：拒绝政治、色情、暴力、辱骂真人、歧视等违规内容

## 🔒 安全设计（重要）

- **API Key 不写死在源码里**，只保存在你本机浏览器的 `localStorage`
- 页面本身不含任何 Key，外发文件也不会泄露你的 Key（但别把已保存 Key 的浏览器配置导出）
- 直连官方 API，不经过任何第三方中转站
- 免费 Key 丢失最多影响免费额度，不涉及财产安全

## 🚀 使用方法

1. 浏览器打开 `index.html`（双击即可，无需服务器）
2. 首次打开会弹出配置框，选择服务商并填入免费 API Key
3. 开始对线。Enter 发送，Shift+Enter 换行

## 🌐 部署到 GitHub Pages（可选）

1. 把本仓库 push 到你的 GitHub 账号
2. 仓库 `Settings` → `Pages` → Source 选 `Deploy from a branch`，分支选 `main`、目录 `/root`，保存
3. 访问 `https://<你的用户名>.github.io/<仓库名>/` 即可在线使用
